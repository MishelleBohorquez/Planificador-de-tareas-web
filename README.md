# Planificador de tareas web

## Descripción

Este proyecto consiste en el desarrollo de una aplicación web creada como parte del **Proyecto Individual CH13** del Bootcamp **Desarrollo Full Stack Java** de Generation Colombia.

El objetivo es aplicar los conocimientos adquiridos en desarrollo Front-End mediante la implementación de una interfaz web utilizando **HTML5, CSS3 y JavaScript**, siguiendo buenas prácticas de programación, control de versiones con Git y la metodología ágil Scrum.

---

## Objetivos

* Aplicar HTML semántico.
* Diseñar una interfaz atractiva y responsive con CSS.
* Implementar funcionalidades utilizando JavaScript.
* Gestionar el desarrollo mediante Git y GitHub.
* Organizar el trabajo utilizando Scrum y un tablero Kanban.
* Desplegar la aplicación para su acceso público.

---

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
* Git
* GitHub
* GitHub Pages

## Metodología de trabajo

El desarrollo del proyecto se realizó siguiendo la metodología **Scrum**, organizando las actividades en Sprints y gestionando las tareas mediante un tablero Kanban en Trello.

---

## Instalación

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` desde un navegador.
